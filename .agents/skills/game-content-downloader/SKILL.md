# Game Content & Additional Pack Downloader

This skill provides comprehensive workflows for discovering, downloading, verifying, and bundling external game asset packs (story acts, live events, weapon offers, audio/animations) directly from CDN servers or live emulator sessions into the standalone APK.

## When to Use
- The game displays a "LOADING REQUIRED! Some content is missing and needs to be updated: SIZE: XX.XX MB" modal.
- A newly unlocked chapter, Act, or raid requires additional downloads during gameplay.
- You want to ensure full offline playability for future game modes (Raid, Underworld, Eclipse, live festivals).
- You need to sync `packs.xml` catalog entries and compute matching cryptographic MD5 companion hashes.

## Game Asset Architecture: How Content Packs Work
Shadow Fight 2 uses a hybrid CDN delivery model:
1. **Catalog Manifest (`config_cdn.xml`)**:
   Contains metadata for every downloadable Unity asset bundle across all platforms (Android, iOS).
   Each entry includes:
   - `Name`: Asset identifier (e.g. `ZONE_2`, `EVENTS/MA_FEST_26`, `OFFERS/WEEKLY_OFFER_14`).
   - `Url`: Direct HTTPS download endpoint on Nekki's CDN (`https://assets.nekki.com/shadowfight/...`).
   - `Size`: Exact byte length.
   - `Hash`: MD5 checksum used for client integrity verification.
2. **Local Pack Registry (`packs.xml` + `packs.xml.hash`)**:
   Located at `/sdcard/Android/data/<package>/files/gamedata/packs.xml`.
   The game engine reads this file on boot to determine which bundles are already installed locally. If a required pack is missing from this file or missing from `bundles/`, the game displays the download modal.

## Method 1: Automated CDN Download (Offline / Scripted)
The bundled script `.agents/skills/game-content-downloader/scripts/download_packs.py` can automatically parse `config_cdn.xml`, download any missing packs in parallel, verify MD5 hashes, and update the catalog.

### Commands

```powershell
# List all available bundles in config_cdn.xml by category
python .agents/skills/game-content-downloader/scripts/download_packs.py

# Download specific missing packs by name
python .agents/skills/game-content-downloader/scripts/download_packs.py --names ZONE_2 ZONE_3

# Download all packs matching a keyword (e.g. all RAID bundles or all EVENT bundles)
python .agents/skills/game-content-downloader/scripts/download_packs.py --pattern EVENT

# Download every single pack in the CDN catalog
python .agents/skills/game-content-downloader/scripts/download_packs.py --all
```

### Script Execution Logic
1. Reads `config_cdn.xml` for target bundles.
2. Dispatches downloads across 6 concurrent worker threads using standard Unity User-Agent headers.
3. Calculates the MD5 checksum of each downloaded file and compares against the CDN manifest.
4. Generates an updated `packs.xml` and recalculates the companion `packs.xml.hash`.

## Method 2: Live Emulator Capture (Intercept via ADB)
If a download dialog appears during live gameplay in BlueStacks, you can let BlueStacks download the files once, then capture them immediately via ADB:

### 1. Identify Downloaded Files
Run an ADB shell search to identify newly created files:
```powershell
& "C:\Program Files\BlueStacks_nxt\HD-Adb.exe" shell ls -laR /sdcard/Android/data/com.nekki.catblasters/files/gamedata/bundles/
```

### 2. Pull Captured Bundles to Repository
```powershell
# Pull specific bundle folders (e.g. EVENTS or OFFERS)
& "C:\Program Files\BlueStacks_nxt\HD-Adb.exe" pull /sdcard/Android/data/com.nekki.catblasters/files/gamedata/bundles/EVENTS modding/assets/downloaded_gamedata/bundles/EVENTS
& "C:\Program Files\BlueStacks_nxt\HD-Adb.exe" pull /sdcard/Android/data/com.nekki.catblasters/files/gamedata/bundles/OFFERS modding/assets/downloaded_gamedata/bundles/OFFERS

# Pull updated packs.xml and hash generated by the game
& "C:\Program Files\BlueStacks_nxt\HD-Adb.exe" pull /sdcard/Android/data/com.nekki.catblasters/files/gamedata/packs.xml modding/assets/downloaded_gamedata/packs.xml
& "C:\Program Files\BlueStacks_nxt\HD-Adb.exe" pull /sdcard/Android/data/com.nekki.catblasters/files/gamedata/packs.xml.hash modding/assets/downloaded_gamedata/packs.xml.hash
```

## Method 3: Integrating into the Self-Extracting APK
Once the asset bundles are downloaded to `modding/assets/downloaded_gamedata/bundles/`:

### 1. Update `AssetExtractor.smali`
Ensure the Smali startup hook extracts the newly acquired files:
```smali
const-string v1, "gamedata/bundles/NEW_CATEGORY/NEW_PACK"
invoke-static {p0, v0, v1}, Lcom/nekki/catblasters/AssetExtractor;->copyAsset(Landroid/content/Context;Ljava/io/File;Ljava/lang/String;)V
```

### 2. Bump Extractor Marker
Always increment the marker file (e.g. from `.all_packs_v2` to `.all_packs_v3`) so that on devices with existing data, the extractor detects the new marker and copies the updated assets.

### 3. Rebuild Standalone APK
```powershell
python modding/pipeline/build_cat_blasters.py
```

## Best Practices & Lessons Learned
1. **Preserve Subdirectory Hierarchy**: Some bundles are organized in subdirectories (`EVENTS/MA_FEST_26`, `OFFERS/WEEKLY_OFFER_12`). In `AssetExtractor.smali`, the `copyAsset` method automatically calls `mkdirs()` on parent directories, so nested paths work seamlessly.
2. **Always Synchronize `packs.xml.hash`**: The game recalculates `MD5(packs.xml)` on startup. If `packs.xml.hash` does not match the exact MD5 of `packs.xml`, the engine discards the local file and re-downloads the catalog from the CDN.
3. **Check Size Sums**: The size displayed in download modals (e.g. `31.58 MB`) equals the exact sum of uncompressed bytes in the missing bundles. Cross-reference this number against `config_cdn.xml` `Size` attributes to pinpoint exactly which bundle group is being requested.
